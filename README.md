# MediCita
> Clínica Santa Cruz — Mayo–Agosto 2026

## Descripción
MediCita es un sistema web de gestión de citas médicas desarrollado para la Clínica Santa Cruz.  
El sistema permite a pacientes reservar citas en línea, consultar historial médico y recibir notificaciones automáticas por correo electrónico.

El proyecto incluye:
- Gestión de pacientes
- Catálogo de médicos y especialidades
- Reserva y administración de citas
- Panel para médicos y recepcionistas
- Historial clínico básico
- Notificaciones mediante EmailJS

## Stack Tecnológico

- Frontend: Vue.js
- Backend: Laravel (PHP)
- Base de Datos: MySQL
- API: REST API
- Notificaciones: EmailJS
- Diseño UI/UX: Figma
- Control de versiones: Git + GitHub

- Registro e inicio de sesión de pacientes

## Instalación y uso

```bash
cd medicita

npm install

npm run dev
```
